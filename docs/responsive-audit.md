# Проверка адаптивности QuestCity

Дата: 14 октября 2026 года.

Проверка выполнена в браузере Chromium через изменение viewport. Это проверка
раскладки, а не запуск на физических телефонах или в Safari/Firefox.

## Размеры

24 ширины: 320, 360, 375, 390, 430, 480, 600, 639, 640, 667, 768, 820,
844, 900, 1023, 1024, 1080, 1279, 1280, 1366, 1440, 1536, 1920, 2560 px.
Высота: 844 px для узких экранов, 900 px для остальных.

Дополнительно: горизонтальная ориентация 568×320, 667×375 и 844×390;
диалог ИИ проверен на 320×568, 360×640, 390×844, 667×375, 844×390,
1024×768 и 1920×1080.

## Покрытие и результат

- Главная, каталог и «Мои квесты».
- Создание, анкета генерации и проверка заполненной анкеты.
- Конструктор черновика, включая все поля и загрузку медиа.
- Страница квеста с картой и карточками остановок.
- Прохождение: ориентир, вопрос, завершение и раскрытый дневник.
- Администрирование с заполненной наградой и двумя местами на карте.
- Вход и регистрация.
- Мобильное меню, выпадающий список, диалог предложения ИИ.

384 замера ширины страницы (включая повторные проверки после исправлений),
24 проверки горизонтальной ориентации и 7 размеров диалога ИИ.
Переполнений документа по горизонтали не обнаружено. Действия диалога
остаются внутри viewport, его содержимое прокручивается отдельно.

Игровые состояния вопроса и завершения, гостевые страницы и предложение ИИ
проверены через отдельный локальный API с тестовыми ответами. Рабочий прогресс,
квесты, награды и партнёрские места при проверке не изменялись.

## Исправления

- Футер использует отдельную планшетную раскладку: исправлено переполнение при 640 px.
- На мобильных ширинах подписи полей размещены над полями и могут переноситься.
- Ввод использует шрифт 16 px на мобильных экранах.
- Области нажатия кнопок со значками, фильтров, навигации и масштаба карты увеличены.
- Мобильное меню помещается на экране 320 px.
- Диалоги ограничены высотой viewport и имеют небольшие мобильные отступы.
- Уменьшены внутренние отступы мобильных карточек и вложенных блоков дневника.
- Длинный текст переносится; заголовки карты и дополнительные метки могут переходить на следующую строку.

Сборка TypeScript/Vite и ESLint проверяются командой:

```sh
cd frontend
npm run build && npm run lint
```

Для проверки перед публичным запуском дополнительно нужны реальные устройства
с Safari/iOS и Chrome/Android: клавиатура, геолокация, системные панели,
воспроизведение аудио и жесты карты.

## Завершение проверки новых игровых механик

14 октября 2026 года проверены формы проводника, фотозагадки, последовательности
и подсказок в конструкторе, а также выбор проводника в генераторе.
Выполнено 27 замеров: ширины 320, 360, 390, 640, 768, 1024, 1280 и 1920 px,
дополнительно последовательность с тремя подсказками проверена при
568×320, 667×375 и 844×390.

Исправлено переполнение конструктора на 3 px при ширине 320 px: мобильная
колонка сетки теперь может сжиматься до доступной ширины. После исправления
переполнений в перечисленных состояниях нет.

Проверены ограничение в три подсказки и сохранение проводника после перезагрузки.
Настройки использованного черновика возвращены в исходное состояние.
Итоговая сборка и ESLint проходят; серверные проверки: 87 тестов и Ruff проходят.
Прохождение нового демо-квеста через интерфейс и API проверено на предыдущем этапе.
