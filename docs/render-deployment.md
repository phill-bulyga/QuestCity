# Размещение демонстрации на Render

`render.yaml` описывает бесплатный веб-сервис и бесплатную PostgreSQL-базу во Франкфурте.
Корневой Dockerfile собирает React и включает его в Python-образ. FastAPI обслуживает
сайт и API с одного HTTPS-адреса: это сохраняет корректную работу refresh-cookie.
База не открыта для внешних подключений. Redis в этой конфигурации не требуется.

Запуск применяет миграции и, при `SEED_DEMO=true`, добавляет демонстрационные квесты.
Автор демонстраций — неактивная служебная запись без известного пароля и без прав
администратора. Локальные пользователи, прохождения и `.env` не переносятся.

## Подключение

1. Разрешить Render доступ к приватному репозиторию `phill-bulyga/QuestCity`.
2. Создать Blueprint из этого репозитория, ветка `main`, файл `render.yaml`.
3. Проверить, что оба ресурса используют тариф Free.
4. После развёртывания открыть выданный адрес `https://....onrender.com`.
5. Зарегистрировать собственный аккаунт на сайте.

JWT-секрет генерируется Render. Cookie использует HTTPS. Генератор ИИ требует
отдельной настройки `LLM_API_KEY` в секретах веб-сервиса. Ключ не записывается в Git
и не переносится из локального окружения автоматически. Его отсутствие не мешает
ручному созданию и прохождению квестов.

## Ограничения бесплатной демонстрации

- Free-сервис засыпает после 15 минут без запросов; следующий запуск может занять около минуты.
- Бесплатная PostgreSQL-база истекает через 30 дней; затем требуется платное продление.
- Загруженные фото и аудио находятся во временной файловой системе и исчезают после
  перезапуска, засыпания или новой публикации. Данные квеста при этом остаются в БД,
  но ссылки на исчезнувшие загрузки перестанут работать.
- Демонстрационные изображения используют внешние ссылки и не зависят от локальных загрузок.
- Открытие точек без GPS включено для демонстрации. Для географического прохождения
  установить `ALLOW_LOCATION_BYPASS=false`.
- Настоящие партнёрские договорённости и погашение промокодов не имитируются.

Для постоянной эксплуатации нужны платная БД, постоянное хранилище файлов,
резервное копирование и отдельная проверка эксплуатационных настроек.
